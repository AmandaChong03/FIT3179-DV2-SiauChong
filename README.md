# Who Cares for Australia's 31.6 Million Pets?

FIT3179 Data Visualisation 2, Monash University. A data story about pets, vets and the cost of care in Australia.

**Live page:** https://amandachong03.github.io/FIT3179-DV2-SiauChong/

## What is in this repository

| Path | What it holds |
|---|---|
| `index.html` | The web page |
| `style.css` | Layout, fonts and colours |
| `charts/` | The 12 charts, one Vega-Lite JSON file each |
| `maps/` | The 3 maps (Vega-Lite JSON) and the Australian state shapes |
| `data/` | The CSV data files the charts and maps read |
| `sketch.pdf` | The hand-drawn sketch of the page |

## Data sources

- Animal Medicines Australia, *Pets in Australia 2025*
- Australian Veterinary Association, *Workforce Survey 2023/24*
- PetSure, *Pet Health Monitor 2026*
- Australian Bureau of Statistics, *Counts of Australian Businesses*, June 2025
- Australian Bureau of Statistics, *National, state and territory population*, June 2025
- RSPCA Australia, annual statistics, 2009–10 to 2024–25
- Australasian Veterinary Boards Council, *Veterinary Science in Australia*, 2025

Links to each source are in the footer of the page.
